# bin/

第一版**故意保持为空**。

`lab-workflow` 只在工具仓库目录内运行，不安装到全局 PATH，也不在这里生成启动脚本。
这样可以确保：

- 命令始终对应仓库里的那一份代码；
- 不会因为 `{{workspace_root}}/bin` 出现在 PATH 中而误用旧版本；
- 工作台数据与工具实现保持清晰分离。

在仓库内使用（Windows 下是 `bin\lab-workflow.cmd`）：

```text
{{lab_cmd}} --help
```

如果以后需要全局安装，应单独评审安装方式、版本升级和数据兼容性。
目录浏览与跳转请安装 try-rs，不需要在这里再放一个入口。
